# 🌿 GreenShop — Full-Stack E-Commerce Project

> ⚠️ **Status:** Work in Progress / Active Development

GreenShop is a full-stack e-commerce web application for buying indoor plants and gardening products.

The project is currently under active development. I am continuously adding new features, improving the UI, and expanding my full-stack development skills.

---

## 🇬🇧 English

### 📌 Description

GreenShop is a personal full-stack e-commerce project focused on building a modern web application for selling indoor plants and gardening products.

The project allows me to practice working with both frontend and backend technologies, REST APIs, databases, and application architecture.

### 🛠️ Tech Stack

**Frontend**
- React 19
- TypeScript
- Vite
- React Router v7
- Sass / SCSS

**Backend**
- Python
- Django 6.0
- Django REST Framework

**Database**
- PostgreSQL

**Other**
- REST API
- CORS
- Git / GitHub

### ✅ Current Features

- [x] Product catalog
- [x] Product categories
- [x] Category filtering
- [x] Product size categories
- [x] Price range filtering
- [x] REST API for products and categories
- [x] Frontend integration with the backend API
- [x] PostgreSQL database integration

### 🚧 Planned Features

- [ ] User authentication and profiles
- [ ] Shopping cart
- [ ] Checkout workflow
- [ ] Order management
- [ ] Payment integration
- [ ] Additional product filtering and sorting
- [ ] Further UI/UX improvements

### 🏗️ Architecture

The application follows a client-server architecture:

**React Frontend → REST API → Django REST Framework → PostgreSQL**

The frontend communicates with the Django backend through REST API endpoints.

### 📂 Project Status

GreenShop is an **ongoing personal project**.

The application is not finished yet, and new functionality is being implemented continuously. Some features listed in the Planned Features section have not been implemented yet.

### 🎯 Purpose

The main goal of the project is to gain practical experience in full-stack web development and understand how frontend, backend, REST APIs, and databases work together in a real application.
