## English Version

### 📋 About the Project

Recidiviz Project is a modern, responsive single-page application (SPA) built to showcase information about criminal justice reform and recidivism reduction initiatives. The project features a clean, professional design with multiple sections highlighting the approach, partnerships, press coverage, and geographic presence of the organization.

### 🚀 Technologies Used

- **React 19.2.4** - Modern JavaScript library for building user interfaces
- **Vite 8.0.1** - Next-generation frontend build tool for fast development
- **SASS** - CSS preprocessor for advanced styling capabilities
- **ESLint** - Code quality and consistency tool
- **JavaScript (ES6+)** - Modern JavaScript features

### 🛠️ Development Tools

- **@vitejs/plugin-react** - Official Vite plugin for React support
- **ESLint plugins** - React Hooks and React Refresh linting
- **Sass compiler** - For SCSS/SASS preprocessing

```

│   ├── section/          # Page sections
│   │   ├── hero/         # Hero section
│   │   ├── steps/        # Steps section
│   │   ├── approach/     # Approach section
│   │   ├── info/         # Info section
│   │   ├── partners/     # Partners section
│   │   ├── information/  # Information section
│   │   ├── press/        # Press section
│   │   └── where/        # Location section
│   ├── assets/           # Images, icons, and media files
│   ├── style/            # SCSS stylesheets
│   ├── App.jsx           # Main application component
```

### 🎨 Features

- **Responsive Design** - Fully optimized for desktop, tablet, and mobile devices
- **Component-Based Architecture** - Modular and maintainable code structure
- **Modern UI/UX** - Clean and professional interface
- **Performance Optimized** - Fast loading with Vite and optimized assets
- **Custom Fonts** - Public Sans, Libre Baskerville, and Muller fonts
- **SVG Icons** - Scalable vector graphics for crisp visuals

### 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/BogdanMosok/portfolio.git
cd recidiviz-project
```

2. Install dependencies:
```bash
npm install
```

### 🚀 Running the Project

**Development mode:**
```bash
npm run dev
```
The application will be available at `http://localhost:5173`

**Build for production:**
```bash
npm run build
```

**Preview production build:**
```bash
npm run preview
```

**Watch SASS files:**
```bash
npm run sass-watch
```

**Lint code:**
```bash
npm run lint
```

## Wersja Polska

### 📋 O Projekcie

Projekt charakteryzuje się czystym, profesjonalnym designem z wieloma sekcjami podkreślającymi podejście, partnerstwa, relacje prasowe i obecność geograficzną organizacji.

- **Pluginy ESLint** - Linting dla React Hooks i React Refresh
